# OBT Apparel

New chat: read `CONTEXT.md` before changing anything. Brand voice is `Brand.md`. Code questions go to the graph first.

```bash
graphify query "your question"
```

Graph file: `graphify-out/graph.json`. From the Graphify MCP, set `project_path` to this repo.

After code changes that should stay in the graph, run `graphify update .`.
